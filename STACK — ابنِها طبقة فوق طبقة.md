# STACK — ابنِها طبقة فوق طبقة

## 🇸🇩 النسخة العربية

**STACK** هو مشروع ويب تجريبي فاخر مستوحى من تجربة **Double Stack Burger**، ومبني حول فكرة:

> **ابنِها طبقة فوق طبقة.**

المشروع لا يركز فقط على عرض البرجر، بل يحوّل عملية بناءه إلى تجربة بصرية وتفاعلية من خلال الحركة، الـScroll، الصور، والتفاصيل الدقيقة.

## ✨ المميزات

- تجربة ويب تفاعلية بطابع فاخر.
- عرض البرجر على شكل **10 طبقات**.
- حركة الطبقات أثناء التمرير.
- شاشة تحميل `Loader` مع مؤشر تقدم.
- تحميل مسبق للصور قبل بدء التجربة.
- تأثيرات `Scroll Reveal`.
- مؤشر فأرة مخصص `Custom Cursor`.
- قائمة تنقل متجاوبة للموبايل.
- تصميم متجاوب مع مختلف أحجام الشاشات.
- أقسام لعرض المكونات والتفاصيل.
- معرض صور للمنتج.
- أزرار وتفاعلات بصرية.
- دعم كامل لاتجاه الكتابة العربي RTL.

## 🎨 التصميم

تم بناء الهوية البصرية للمشروع باستخدام ألوان داكنة وفاخرة تجمع بين:

- الأسود والـCharcoal.
- Burgundy.
- Gold.
- Cream.

ويستخدم المشروع خط **IBM Plex Sans Arabic** للنصوص العربية و **IBM Plex Mono** للعناصر الإنجليزية والتفاصيل التقنية. 

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Intersection Observer API
- CSS Animations & Transitions
- Responsive Web Design

## ⚙️ التفاعل والحركة

يحتوي المشروع على نظام JavaScript مسؤول عن:

- تحميل الصور مسبقاً.
- حساب نسبة التحميل وعرضها.
- إخفاء شاشة التحميل بعد اكتمال التحميل.
- التحكم في الـNavigation.
- فتح وإغلاق قائمة الموبايل.
- الانتقال السلس بين الأقسام.
- تشغيل العناصر عند ظهورها أثناء الـScroll.
- إدارة التفاعلات البصرية.

# STACK — Build It Layer by Layer

## 🇬🇧 English Version

**STACK** is a premium creative web experience inspired by the **Double Stack Burger**, built around one simple concept:

> **Build it layer by layer.**

Instead of simply presenting a burger, the project turns the building process into an interactive visual experience using motion, scrolling, imagery, and carefully designed details.

## ✨ Features

- Premium interactive web experience.
- **10-layer** burger presentation.
- Layer animations while scrolling.
- Loading screen with progress indicator.
- Image preloading before the experience starts.
- Scroll reveal animations.
- Custom cursor interactions.
- Responsive navigation with mobile menu.
- Responsive layout for different screen sizes.
- Ingredient and product sections.
- Product image gallery.
- Interactive visual elements.
- Full RTL Arabic support.

## 🎨 Design

The visual identity uses a dark premium palette combining:

- Black and Charcoal.
- Burgundy.
- Gold.
- Cream.

The project uses **IBM Plex Sans Arabic** for Arabic content and **IBM Plex Mono** for English and technical elements. 

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Intersection Observer API
- CSS Animations & Transitions
- Responsive Web Design

## ⚙️ Interactions & Motion

The JavaScript layer handles:

- Image preloading.
- Loading progress calculation.
- Loader completion and transition.
- Navigation behavior.
- Mobile menu interactions.
- Smooth section navigation.
- Scroll-based reveal animations.
- Interactive visual effects.
